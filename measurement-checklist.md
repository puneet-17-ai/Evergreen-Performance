# Lighthouse measurement checklist

- [ ] Serve the project locally or deploy both versions to equivalent environments.
- [ ] Use the same Chrome version and Lighthouse mode for both tests.
- [ ] Record three runs for each version and compare the median.
- [ ] Record Performance, Accessibility, Best Practices, SEO, LCP, CLS and Total Blocking Time.
- [ ] Add screenshots of the Lighthouse reports to your submission if allowed.
- [ ] Never enter estimated scores as measured scores.
